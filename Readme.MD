## 🌟 About the Project

**DeepSeek AI Project** is a hands-on Generative AI project focused on exploring and working with modern **Large Language Models (LLMs)**.

The project experiments with **DeepSeek**, **OpenRouter**, and **Claude** using Python scripts and Jupyter Notebooks.

It demonstrates how AI models can be accessed through APIs, how prompts can be processed, and how different LLMs can be explored for Generative AI applications.

---

## 🎯 Project Objectives

The main objectives of this project are:

- 🤖 Explore **DeepSeek AI models**
- 🔌 Understand **OpenRouter API integration**
- 🧠 Experiment with **Claude models**
- 🐍 Integrate LLMs with **Python**
- 💬 Work with prompts and AI-generated responses
- 📊 Explore differences between different LLMs
- 🔐 Learn secure API key management
- 🧪 Perform practical Generative AI experiments
